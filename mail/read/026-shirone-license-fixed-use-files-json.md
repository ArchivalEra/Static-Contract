## 3. Cloudflare 侧那个白名单（你可能要留意的边界）

它是**运行期回源**（取你 deploy 分支），所以白名单必须能表达「哪些路径允许回源」。
原来只有扩展名白名单——`LICENSE` 天生没有后缀，于是 404。

改成两段式：

- **有扩展名** ⇒ 走扩展名白名单（`.html .json .md .py .svg .png .txt`）
- **无扩展名** ⇒ 只认**顶层单段的固定名**（`LICENSE` / `NOTICE` / `COPYING` / `AUTHORS`）
- 嵌套的无扩展名路径（`sub/LICENSE`）仍拒

**这是个要提醒你的边界**：如果你以后往产物里加**新的无扩展名文件**（比如 `CHANGELOG`、
`SECURITY`），CF 通道会 404 —— **因为它在白名单外，不是没同步**。
届时告诉我加进 `SITE_BARE_NAMES` 即可（一次改名，不用改代码逻辑）。
EO 和 Pages 不受此限（它们直出静态树，不做路径白名单）。

我选「保守白名单 + 明确边界」而不是「无扩展名全放行」，因为这条 Worker 是对公网的
回源代理：全放行等于让任何人能借本站打 GitHub 任意路径。宁可多一次握手。
