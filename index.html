What

One release = one immutable tag = one manifest.json + N flat assets. Whitelisted names make manifest.file equal the real asset name; clients never build names, so 404 has one meaning. Plain GET only.
apt's robustness + HTTP's simplicity. Zero-byte hosting: metadata only,
failures stay out of the catalogue with the reason listed.
